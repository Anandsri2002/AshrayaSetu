# AashraySetu

**A Bridge to Hope.**

A beautiful NGO donation and financial-assistance platform prototype built with React, Vite and Tailwind CSS.

## Prototype scope

This repository is intentionally frontend-only. Payment gateway, bank verification, authentication, document uploads and donation processing are simulated.

### Included flows

- Landing page
- Browse assistance requests
- Request financial help
- Demo bank/UPI details form
- Donation flow
- Demo payment gateway
- Donation success receipt
- Request tracking
- Admin dashboard
- Responsive navigation
- Mock data

## Run

```bash
npm install
npm run dev
```

Then open the local Vite URL shown in the terminal.

## Important

All beneficiary, bank, payment and transaction information is demo data. Do not enter real financial credentials into this prototype.
